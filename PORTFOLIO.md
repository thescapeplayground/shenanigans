# Portfolio Site Structure & Development Guidelines

This document details the visual identity, structure, and instructions for building and editing **Shenanigans v3.0 (Leonardo's Terrace)** (`isaiahscape`).

> [!IMPORTANT]
> **Instructions for AI Coding Assistants:**
> 1. Read this file at the start of any conversation or task.
> 2. Whenever you make structural, stylistic, or feature changes to the site, update this file immediately to document the new state.
> 3. Keep the styling clean and strictly adhere to the digital grid design system. Avoid introducing physical collage elements (notebook bindings, paper clips, stamp scalloping, washi tape) or handwritten script fonts like `Caveat`.

## 1. Visual Identity & Design System

The site adheres to a sleek, warm, coffee-inspired digital grid aesthetic with a global tactile paper texture overlay:
- **Core Background**: Oat latte cream (`--bg-tan` / `#efe7dd`) in light mode and dark espresso roast (`#12100e`) in dark mode.
- **Typography**: Clean display and sans-serif fonts using the variable font `Aspekta` (`--sans` / AspektaVF). Monospaced fonts for status/meta lines (`--mono`).
- **Card Panels**: Translucent warm cream/espresso panels (`--card-bg`) with fine borders (`--border-color`) and rounded corners.
- **Accents**: Roasted caramel crema (`--accent` / `#9c5c34` light, `#d49a6a` dark) paired with high-contrast espresso/steamed-milk typography (`--text-dark`, `--text-muted`).

## 3. Maintenance Procedures

1. **Asset Manifest**: Run `node generate-manifest.js` (automatically invoked by `npm run dev` and `npm run build`) after adding items to `public/projects/`, `public/logos/`, `public/designs/`, or `public/photography/`.
2. **Build Check**: Run `npm run build` (`node generate-manifest.js && tsc -b && vite build`) in the project root to validate TypeScript types and the Vite bundle.
